# Sorting Visualizer

Welcome to the **Sorting Visualizer** project! This web application provides an interactive platform to visualize different sorting algorithms in action, built with **Next.js** for the frontend.

---

## 🌟 **Features**

- **Interactive Visualization**: Watch sorting algorithms step-by-step.
- **Customizable Inputs**: Set array size and speed of visualization.
- **Multiple Algorithms**: Includes popular sorting algorithms like Bubble Sort, Merge Sort, Quick Sort, and more.
- **Responsive Design**: Optimized for both desktop and mobile devices.

---

## 🚀 **Tech Stack**

- **Frontend**:
  - **Next.js**: For building the user interface.
  - **CSS3**: For styling and responsive design.

## 🛠️ **Installation and Setup**

### Prerequisites

Ensure you have the following installed:
- [Node.js](https://nodejs.org/) (v16 or later).
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/) for package management.

### Installation Steps

1. **Clone the repository**:
    ```bash
    git clone https://github.com/ShashiShekharDixit/Sorting-Visualization.git
    cd sorting-visualizer
    ```

2. **Install dependencies**:
    ```bash
    npm install
    ```
    or
    ```bash
    yarn install
    ```

3. **Start the development server**:
    ```bash
    npm run dev
    ```
    or
    ```bash
    yarn dev
    ```

4. **Access the application**:
    Open your browser and navigate to `http://localhost:3000`.

---

## 💻 **Usage**

- Select a sorting algorithm from the options.
- Adjust the array size and sorting speed using the controls.
- Click "Sort" to visualize the sorting process.
- Use "Reset" to start over with a new array.

### Customization

- **Add New Algorithms**: Implement additional algorithms in the code.
- **Modify Styles**: Update the CSS files to change the visual appearance of the application.
